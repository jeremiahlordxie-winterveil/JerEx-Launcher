JEL 0.1.0 development release

JEL is a Windows x64 ChatGPT launcher. It discovers the installed ChatGPT app,
checks local HTTP/SOCKS5 proxy paths, and asks before changing ChatGPT's .env.

Requirements
- Windows 10/11 x64
- The official ChatGPT desktop app

Install
Run JEL-Setup-0.1.0-win-x64.exe. The installer is per-user and does not need
administrator permission. Existing .codex, .env, JEL settings and logs are kept.

Diagnostics
Use the Diagnostics only button to inspect the detected environment without
changing ChatGPT's .env or restarting ChatGPT.

This development build is not code-signed. GitHub publication and signing are
handled in a separate workspace.
